# 宠物养成系统

第一阶段是一个 C++17 单宠物控制台游戏。领养一只猫、狗或兔子，给它起名，然后通过菜单查看状态、喂食、玩耍、休息、清洁或抚摸。选择 `0` 结束本次游戏。宠物状态只在这次运行中有效。

## 在 Windows 上运行

双击项目中随附的 `bin\VirtualPetSimulator.exe`，或在 PowerShell 中运行以下命令。可执行文件为 Windows x64 Release 版。

```powershell
Set-Location -LiteralPath 'D:\面向程序设计实践\VirtualPetSimulator'
.\bin\VirtualPetSimulator.exe
```

## 从源码编译

在 Visual Studio 2026 安装程序中选择“使用 C++ 的桌面开发”，并包含适用于 Windows 的 C++ CMake 工具。源码使用 UTF-8，CMake 为 MSVC 启用 `/utf-8`。项目使用 C++ 标准库和 Windows 自带的控制台 API。

**在 Visual Studio 中**，用“文件 → 打开 → 文件夹”打开含 `CMakeLists.txt` 的项目根目录。等待 CMake 配置完成，选择 `VirtualPetSimulator.exe` 作为启动项，按 `Ctrl+F5` 运行。

**在命令行中**，打开 Visual Studio 2026 的 Developer PowerShell，使用支持 `Visual Studio 18 2026` 生成器的 CMake，在项目根目录执行以下命令。

```powershell
cmake -S . -B build -G "Visual Studio 18 2026" -A x64
cmake --build build --config Release
.\build\Release\VirtualPetSimulator.exe
```

自己编译的程序位于 `build\Release`。修改源码后再次执行第二、三行即可运行新版本。

## 游戏规则

所有宠物初始为 1 级，经验 0，饱腹度 50，健康值 100，心情 80，精力 70，清洁度 80，亲密度 0。名称可以包含中文和内部空格。名称为空或仅含空格时，界面会提示重新输入。

| 菜单 | 操作 | 属性变化 |
| --- | --- | --- |
| 1 | 查看状态 | 显示名称、种类、等级和全部数值 |
| 2 | 喂食 | 饱腹度 +20 |
| 3 | 玩耍 | 猫玩毛线球，心情 +15、精力 −8；狗玩飞盘，心情 +20、精力 −15；兔子跳跃，心情 +12、精力 −6 |
| 4 | 休息 | 精力 +30 |
| 5 | 清洁 | 清洁度 +25 |
| 6 | 抚摸 | 亲密度 +5，心情 +5 |
| 0 | 退出 | 结束本次游戏 |

六项状态值的取值范围为 0～100。精力恰好等于玩耍消耗时可以玩，精力不足时会收到提示，心情和精力都保持原值。等级、经验和健康值在本阶段维持初始值。

## 快速验收

1. 领养猫并命名为“小橘”，输入 `1` 查看初始状态。
2. 输入 `3` 玩毛线球，再输入 `1`。心情应为 95，精力应为 62。
3. 继续玩 7 次后精力为 6。再玩一次应提示精力不足。休息一次后精力为 36，可以重新玩耍。
4. 重启后分别领养狗和兔子。第一次玩耍后，狗的心情和精力应为 100、55，兔子应为 92、64。
5. 在主菜单输入 `3abc`，应收到输入提示。随后输入 `1` 可以继续查看状态。

| 边界示例 | 猫在精力恰为 8 时仍可玩一次，精力降至 0。再次玩耍被拒绝，休息后可重新玩耍。 |
