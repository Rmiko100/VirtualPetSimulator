# 宠物养成系统

VirtualPetSimulator 是一个用 C++17 编写的单宠物控制台游戏。第二阶段加入回合制时间、属性自然变化、经验升级和成长阶段。领养一只猫、狗或兔子并为它命名后，游戏从第 1 天 08:00 开始。输入 `0` 可结束本次游戏。

## 运行与编译

Windows x64 用户可以直接双击 `bin\VirtualPetSimulator.exe`。本项目使用 C++ 标准库及 Windows 自带的控制台 API。源文件、重定向输入和输出均使用 UTF-8。

在 Visual Studio 2026 安装程序中选择“使用 C++ 的桌面开发”和适用于 Windows 的 C++ CMake 工具。用“文件 → 打开 → 文件夹”打开含 `CMakeLists.txt` 的目录，选择 `VirtualPetSimulator.exe`，按 `Ctrl+F5` 运行。

也可以在 Visual Studio 2026 的 Developer PowerShell 中执行以下命令。使用支持 `Visual Studio 18 2026` 生成器的 CMake。

```powershell
Set-Location -LiteralPath 'D:\面向程序设计实践\VirtualPetSimulator'
cmake -S . -B build -G "Visual Studio 18 2026" -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
.\build\Release\VirtualPetSimulator.exe
```

## 每个回合做什么

菜单持续显示当前时间、宠物状态、成长阶段和升级进度。初始为 1 级、经验 0，饱腹度 50、健康值 100、心情 80、精力 70、清洁度 80、亲密度 0。

| 编号 | 操作 | 直接效果 | 游戏分钟 | 经验 |
| --- | --- | --- | ---: | ---: |
| 1 | 查看状态 | 查看当前各项数值及提示 | 0 | 0 |
| 2 | 喂食 | 饱腹度 +20 | 15 | 10 |
| 3 | 玩耍 | 猫玩毛线球，心情 +15、精力 −8。狗玩飞盘，心情 +20、精力 −15。兔子跳跃，心情 +12、精力 −6。 | 30 | 20 |
| 4 | 休息 | 精力 +30，休息期间免除每小时的精力损失 | 120 | 5 |
| 5 | 清洁 | 清洁度 +25 | 15 | 10 |
| 6 | 抚摸 | 亲密度 +5，心情 +5 | 5 | 5 |
| 7 | 等待一小时 | 推进时间，结算自然变化 | 60 | 0 |
| 0 | 退出 | 结束游戏 | 0 | 0 |

饱腹度、健康、心情、精力、清洁度和亲密度都限制在 0～100。互动至少改变一项直接相关属性才会结算该行的时间和经验。例如，猫的心情已满，只要能消耗 8 点精力仍可玩毛线球。饱腹度已满时重复喂食、精力不足时玩耍或输入非法选项，时钟和经验都保持原值。主动等待随时可用。

## 整点衰减与成长

- 互动先生效，游戏时钟随后前进。每跨一个整点，饱腹度 −5、心情 −2、清洁度 −2，普通活动期间精力再 −3。亲密度保持原值。上回合留下的分钟会带入下回合。
- 每小时结算后，若饱腹度低于 20，健康值 −5；若清洁度低于 20，健康值 −3。两项同时满足时健康值 −8。恰好为 20 时，这一项不会触发扣血。
- 饱腹度、精力、心情或清洁度低于 20 时会出现对应提示。健康值低于 30 时会提示健康较差，降至 0 时显示危急提示，玩家仍可继续照顾宠物。
- 当前等级乘以 100 即升至下一级所需的经验。升级时扣除该级所需经验，剩余值带入下一级。1～4 级为幼年期，5～9 级为成长期，10 级起为成年期。升级和进入新阶段都会在操作结果中提示。

## 三步复核一小时的结算

领养一只猫，从初始状态依次输入 `3`、`3`、`4`。

| 操作后 | 时间 | 饱腹度 | 心情 | 精力 | 清洁度 | 当前经验 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 第一次玩毛线球 | 第 1 天 08:30 | 50 | 95 | 62 | 80 | 20 / 100 |
| 第二次玩毛线球 | 第 1 天 09:00 | 45 | 98 | 51 | 78 | 40 / 100 |
| 休息两小时 | 第 1 天 11:00 | 35 | 94 | 81 | 74 | 45 / 100 |

第二阶段已使用 Visual Studio Community 2026 和 MSVC 19.51 构建，并通过两项 CTest 验收。`Phase2.Core` 包含 7 组核心规则测试，覆盖跨天、休息、属性边界、健康惩罚叠加、大额经验、连续升级和三种宠物的多态行为。`Phase2.Console` 通过实际菜单验证中文命名、查看状态、非法输入、等待及退出。文件职责、回合结算过程和 C++ 知识点见[架构说明](Docs/Architecture.md)。
